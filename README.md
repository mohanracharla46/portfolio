# Mohan Racharla — Personal Developer Portfolio

A premium, highly interactive personal portfolio website built for **Mohan Racharla** (Full-Stack Developer & Founder of CodeNative).

Inspired by modern experimental motion design, editorial typography, continuous scroll storytelling, and digital product studio aesthetics.

2. **REFERITUP** ([referitup.com](https://referitup.com/)) — Growth and referral automation platform.

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite
- **Language**: JavaScript (ES6+)
- **Animation**: GSAP (GreenSock) + GSAP ScrollTrigger
- **Smooth Scroll**: Lenis Smooth Scroll
- **Styling**: Vanilla CSS (Custom Design System with CSS Variables)
- **Icons**: Lucide React & Custom SVG Social Icons

## ⚡ Key Features

- **Continuous Scroll Storytelling**: Locked section morphing and text reveals powered by GSAP ScrollTrigger scrub.
- **Scroll-Driven Developer Portrait**: Masked portrait container that unclips, scales, and shifts in parallax as the user scrolls down.
- **Custom Dynamic Cursor**: Context-aware desktop cursor that transforms with custom labels (`VIEW`, `VISIT`, `BUILD`, `COPY`) over interactive elements.
- **Interactive UI Showcases**: Live code compiler preview, referral dashboard counter, telematics SVG charts, and analytics report cards.
- **Brand Loading Experience**: Initial 1.2s initializing sequence with neon citron progress bar.

## 📥 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/mohanracharla46/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build production bundle**:
   ```bash
   npm run build
   ```
